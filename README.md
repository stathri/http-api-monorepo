# http-api-monorepo

Collection of HTTP APIs written in various languages for use in HiddenDevs skill role applications.

All APIs perform _somewhat_ the same, in that they contain similar routes and responses - just written in different languages.

**Warning:** None of these APIs should be used in production. Do not run them on a production server.
Although some/all have features like logging, versioning, request validation, etc., they are merely examples to show proficiency in each language.
